# syntaxlm

`syntaxlm` is a tiny, dependency-free syntax-highlighting model. It reads source code, tokenizes it, and predicts a highlighting class for each token. The model is a compact averaged perceptron, so it trains in seconds on a laptop and produces a small JSON model.

This is deliberately a first experiment, not a replacement for a full parser. The useful research question is whether a small learned model can recover enough context to make highlighting feel natural, while remaining cheap enough to run in an editor.

## Quick start

```bash
python3 syntaxlm.py train --output syntaxlm.json
printf 'def greet(name):\n    return "hello " + name\n' \
  | python3 syntaxlm.py highlight --language python --model syntaxlm.json
```

The default output is JSON spans:

```json
{"language":"python","spans":[{"start":0,"end":3,"kind":"keyword","text":"def"}]}
```

For terminal output:

```bash
cat example.py | python3 syntaxlm.py highlight --language python --format ansi
```

For a Kotlin consumer, export the model as the portable matrix binary:

```bash
python3 syntaxlm.py train --output syntaxlm.matrix.bin --format bin
kotlinc src/main/kotlin/syntaxlm/SyntaxLm.kt -d syntaxlm-kotlin.jar
printf 'fun twice(x: Int) = x * 2\n' \
  | kotlin -classpath syntaxlm-kotlin.jar syntaxlm.SyntaxLmRunner syntaxlm.matrix.bin kotlin
```

In an app, place `syntaxlm.matrix.bin` in assets/resources and use the provider:

```kotlin
val provider = SyntaxHighlightProvider(context.assets.open("syntaxlm.matrix.bin"))
val spans = provider.highlight(source, "kotlin")
```

The binary is `SYLM` version 1: a UTF-8 feature vocabulary followed by one little-endian float32 row per feature, with columns in this fixed order: `plain`, `keyword`, `name`, `function`, `type`, `builtin`, `string`, `number`, `comment`, `operator`, `punctuation`, `decorator`.

## Training on annotations

The trainer accepts JSONL. Each line contains source and manually labeled spans:

```json
{"language":"python","code":"def add(a, b): return a + b","spans":[{"start":0,"end":3,"kind":"keyword"},{"start":4,"end":7,"kind":"function"}]}
```

Train it with:

```bash
python3 syntaxlm.py train --data labels.jsonl --output my-model.json --epochs 8
```

When annotations are absent, the bootstrap labels are generated by the small built-in lexer. This gives us a runnable baseline immediately; real editor quality will come from replacing or augmenting that corpus with labeled examples. Annotation offsets in the JSONL trainer are Python source-string offsets; use ASCII or convert offsets when annotating non-ASCII source.

## Design

- source offsets are preserved; the Python CLI and Kotlin provider expose UTF-16 offsets, matching Kotlin/JVM `String` indexing;
- whitespace is not emitted as a span;
- features include token text, token shape, lexical hints, neighboring tokens, and the previous predicted class;
- the classifier is intentionally small and inspectable;
- supported lexer hints: Python, JavaScript/TypeScript, JSON, and a generic C-like fallback.

The next useful experiments are adding a larger annotated corpus, measuring token-level accuracy and span F1, and comparing this model with a tiny character-level transformer.
